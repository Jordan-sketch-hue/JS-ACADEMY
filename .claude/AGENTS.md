## 🔴 Lead Generation SOP — Jamaica Yellow Pages + Directories

### Primary Source: Yellow Pages JA
**URL pattern:**
```
https://www.yellowpagesja.com/search/?q=KEYWORD&l=PARISH
```

Parish values: `St.+Ann` | `Portland` | `St.+Mary` | `St.+Thomas` | `Kingston` | `St.+James`

**Puppeteer scrape pattern:**
```ts
await page.goto(`https://www.yellowpagesja.com/search/?q=${query}&l=${parish}`, {
  waitUntil: "domcontentloaded", timeout: 30000
});
// Selectors (verified 2026):
// Name:    .listing-name  OR  h3.biz-name
// Phone:   [href^="tel:"]  OR  .biz-phone
// Address: .biz-address  OR  .address
// Paginate: a.next, .pagination .next
```

**Other JA Sources (priority order):**
| Source | Pattern |
|--------|---------|
| Yellow Pages JA | `yellowpagesja.com/search/?q=X&l=PARISH` |
| BusinessFinda | `businessfinda.com/jamaica/search?q=X&where=PARISH` |
| Jamaica Biz Dir | `jamaica-business-directory.com/?s=X+PARISH` |
| Google Maps | `google.com/maps/search/X+PARISH+Jamaica` (scroll-load) |
| JAMPRO | `jamprocorporation.com` (formal registered businesses) |

### Run Scrapers
```bash
npx ts-node -r dotenv/config scripts/scraper.ts       # live scrape
npx ts-node -r dotenv/config scripts/seed-parishes.ts  # seed researched list
```

### B2B Score Formula
```
phone=+30 | email=+25 | address=+15 | co-op/ltd=+20 | wholesale/depot=+10
≥60 = High priority | 35-59 = Medium | <35 = Low
```

### Dedup Rule
Phone → exact match first. Fallback: business_name + parish combo.
